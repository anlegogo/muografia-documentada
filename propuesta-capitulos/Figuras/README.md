# Figuras

Contiene las figuras de los capítulos 2, 3 y 4 en PDF vectorial, con el nombre exacto que usa cada capítulo, y el logotipo UIS de la plantilla.

Las fuentes están en `fuentes/`: un archivo `.tex` o `.py` por figura, con el mismo nombre que su PDF. Esa carpeta incluye también los datos verificados, `generar_figuras.py`, `requirements.txt` y un `README.md` con la procedencia de cada figura.
